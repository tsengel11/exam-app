# 📘 DP-700 Exam Prep Quiz App (Microsoft Certified: Fabric Data Engineer Associate)

This Streamlit-based quiz application helps you practice for the **DP-700: Microsoft Certified Fabric Data Engineer Associate** certification. It presents multiple-choice questions from a CSV file, tracks your score, provides immediate feedback, and supports shuffling, scoring, and section-based learning.

---

## 🚀 Features

- ✅ Supports CSV-based question import
- ✅ One-question-at-a-time flow
- ✅ Immediate answer feedback with explanations
- ✅ Score tracking and quiz summary
- ✅ Question shuffling for each attempt
- ✅ Section-based practice: Analytics, Ingestion, Monitoring
